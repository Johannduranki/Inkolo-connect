# SOP 04 - Community Admin Dashboard

## Purpose

This SOP explains how a community administrator manages one community.

## Community Position In The Hierarchy

Duranki -> Tenant -> Community

A community must always belong to a tenant.

## Main Responsibilities

- Manage community information.
- View members.
- Manage community services.
- Monitor transactions.
- Manage communications.
- View reports.
- Support members with signup and service applications.

## Daily Start Procedure

1. Sign in with the community admin phone number and PIN/password.
2. Use the dashboard switcher if needed.
3. Select the correct community.
4. Check members, services, transactions, announcements, and reports.

## Check Community Details

1. Open Community Information.
2. Confirm name, type, location, contact details, logo, and status.
3. Report any incorrect tenant/community link to Duranki Admin.

## Manage Members

1. Open Members.
2. Search for a member by name or phone number.
3. Confirm the member belongs to the correct community.
4. Help the member update profile details if required.
5. Check whether the member has paid Community Membership if required.

## Manage Services

1. Open Services.
2. View active services for the community.
3. Confirm the services match what the tenant approved.
4. If a service is missing, ask the tenant admin or Duranki admin to enable it.

## Community Membership Follow-Up

If Community Membership is enabled:

1. Identify unpaid members.
2. Explain that full access requires payment.
3. Ask the member to open Community Membership on the dashboard.
4. Help them pay by Duranki Wallet or bank card.
5. Confirm the service becomes active after payment.

## Grant Distribution Communities

For grant communities such as Traders KZN:

1. Review grant applications.
2. Check approval status.
3. Track payment status.
4. Track reconciliation status.
5. Confirm only the correct trader sees their own record on the member dashboard.
6. Escalate duplicate or incorrect payment records immediately.

## Trader Training Communities

1. Confirm Trader Training is enabled for the community.
2. Check participant progress.
3. Review module completion.
4. Review funding milestones.
5. Confirm training completion comes from quiz/exercise progress, not manual member marking.

## Communications

1. Create announcements for the correct target group.
2. Select the community or subgroup.
3. Write a clear message.
4. Send.
5. Monitor member responses where applicable.

## Control Checks

Every week, confirm:

- Member count is reasonable.
- Community Membership payments are up to date.
- Services appear correctly for members.
- Grant/training data belongs only to the correct community.
- Announcements are sent to the correct target group.
