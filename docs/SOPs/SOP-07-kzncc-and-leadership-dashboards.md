# SOP 07 - KZNCC And Leadership Dashboards

## Purpose

This SOP explains how KZNCC users, KZNCC admins, pastors, bishops, and other leadership users should use their dashboards.

## Dashboard Routes

- KZNCC User: `/dashboard/kzncc-user`
- KZNCC Admin: `/dashboard/kzncc-admin`
- Pastor: `/dashboard/pastor`
- Bishop: `/dashboard/bishop`
- KZNCC Service: `/kzncc`

## KZNCC User Responsibilities

- View KZNCC announcements.
- View KZNCC events.
- Receive official messages.
- Access KZNCC services if subscribed.

## KZNCC Admin Responsibilities

- Manage KZNCC announcements.
- Manage KZNCC events.
- Communicate with members and leaders.
- Review KZNCC revenue and wallet information.
- Review paid membership information.

## Pastor Dashboard Responsibilities

- View assigned church/community information.
- View member activity.
- Review community wallet summary where available.
- Communicate with members.
- Support community registrations and service usage.

## Bishop Dashboard Responsibilities

- View assigned churches/communities.
- Review wallet and revenue summaries across assigned communities.
- Monitor membership, tithes, offerings, and service revenue where available.
- Support pastors and community leaders.

## Daily Start Procedure

1. Sign in using the assigned phone number and PIN/password.
2. Use the role switcher if the user has more than one role.
3. Select the correct dashboard.
4. Review messages, announcements, events, wallet summary, and community activity.

## Send Announcements

1. Open the announcement or communication section.
2. Choose target audience.
3. Write a clear message.
4. Confirm the message is for the correct group.
5. Send.

## Review Wallet And Revenue

1. Open wallet or revenue section.
2. Review total balance.
3. Review monthly share.
4. Review pending payouts.
5. Check transactions.
6. Escalate incorrect totals.

## Member Support

When helping a member:

1. Confirm their cellphone number.
2. Confirm their community.
3. Check whether Community Membership is required and paid.
4. Confirm the service is enabled for the community.
5. Help the member apply for the service.

## Control Checks

Every week, confirm:

- Announcements are current.
- Events are correct.
- Wallet totals look reasonable.
- Member issues are escalated.
- Leadership users have the correct role access.
