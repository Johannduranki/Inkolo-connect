# SOP 06 - Service Provider Dashboard

## Purpose

This SOP explains how service provider administrators and users manage service-specific operations.

## Access

Routes:

- `/dashboard/service-provider-admin`
- `/dashboard/service-provider-user`

Examples of service providers:

- Vuma Force
- Funeral cover provider
- Financial service provider
- Training or grant partner

## Service Provider Admin Responsibilities

- View service performance.
- View members using the service.
- Review payments.
- Upload or manage member documents.
- View billing cycles.
- Generate invoices.
- Monitor service revenue and outstanding items.
- Communicate with target groups if available.

## Service Provider User Responsibilities

- View assigned member/service records.
- Check payment or policy status.
- Upload documents if permitted.
- Support operational work without full admin rights.

## Daily Start Procedure

1. Sign in with service provider credentials.
2. Confirm the correct service provider dashboard is selected.
3. Review summary cards.
4. Check active members, pending members, cancelled members, payments, and documents.
5. Work through outstanding items.

## Review Members

1. Open Members.
2. Search for the member.
3. Confirm community and service.
4. Check product/policy/service status.
5. Check payment status.
6. Check document status.

## Upload Member Documents

1. Find the member record.
2. Select Upload.
3. Choose the correct file.
4. Confirm the file belongs to the correct member and service.
5. Upload.
6. Check that document status changed.

## Billing And Invoices

1. Open Billing.
2. Select the billing cycle.
3. Review paid, failed, and overdue payments.
4. Generate invoices only from confirmed paid members.
5. Check invoice totals.
6. Save or send the invoice according to company process.

## Vuma Force Dashboard Notes

For Vuma Force:

1. View all users and internet spend.
2. Review breakdown per community.
3. Review ISP to micro ISP performance.
4. Monitor live received amount counter.
5. Use communication tools to target areas, districts, groups, or communities.

## Control Checks

Before closing the day:

- All uploaded documents are linked to the correct member.
- Paid members are counted correctly.
- Invoices match paid records.
- Failed or unexpected payments are escalated.
- Service reports match the correct community and tenant.
