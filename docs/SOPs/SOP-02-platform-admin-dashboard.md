# SOP 02 - Duranki Platform Admin Dashboard

## Purpose

This SOP explains how a Duranki Platform Admin manages the full platform.

## Access

Route:

`/dashboard/platform-admin`

The platform admin has the highest access level and can move between:

Duranki -> Tenant -> Community

without logging out.

## Main Responsibilities

- View all tenants.
- Create tenants.
- Configure tenant details.
- Enable or disable tenant services.
- View all communities.
- Enter tenant dashboards.
- Enter community dashboards.
- Configure central Duranki services.
- Manage service pricing, dashboards, and service admin users.
- Review users, transactions, reports, and platform activity.

## Daily Start Procedure

1. Sign in with the authorised platform admin phone number and PIN/password.
2. Confirm you are on the Duranki Platform dashboard.
3. Check the top dashboard switcher.
4. Review the platform totals: tenants, communities, users, transactions.
5. Check whether any tenant or service needs attention.

## Create A New Tenant

1. Select Create New Tenant.
2. Enter tenant name.
3. Enter company name.
4. Enter registration number if available.
5. Enter contact person.
6. Enter email and telephone.
7. Enter address and country.
8. Add tenant website or subdomain.
9. Set status to Configured or Active.
10. Create the tenant administrator details.
11. Save the tenant.

After creation, the tenant receives login details and completes their own setup.

## Configure Tenant Services

1. Open the tenant from the tenant list.
2. Go to Services.
3. Tick the services the tenant may use.
4. Untick services that should not be available.
5. Save changes.

Important: A community can only use services enabled for its tenant.

## Configure Service Pricing And Dashboard

1. Go to the service catalogue area.
2. Select the service.
3. Enter or update service price.
4. Confirm dashboard name.
5. Confirm dashboard route.
6. Add service admin user details if needed.
7. Save the service configuration.

Examples:

- Community Membership: monthly member access fee.
- Trader Training: training module and funding milestone service.
- Grant Distribution: grant approval and reconciliation service.
- Vuma Force: connectivity and micro ISP service.

## Enter A Tenant Dashboard

1. Select the tenant from the tenant list.
2. Click Open Tenant or switch to Tenant view.
3. Review that tenant's communities, services, users, revenue, and settings.

## Enter A Community Dashboard

1. Open a tenant.
2. Select the community under that tenant.
3. Click Open Community or switch to Community view.
4. Review the community details and enabled services.

## Add A New Service To The Platform

1. Go to the service catalogue.
2. Select Add Service.
3. Enter service name.
4. Enter category.
5. Enter service description.
6. Enter price.
7. Enter dashboard name.
8. Enter dashboard route.
9. Add service admin users if applicable.
10. Save.

## Control Checks

Before activating a tenant or service, confirm:

- Tenant details are correct.
- Tenant administrator contact details are correct.
- Services are correctly selected.
- Pricing and fees are correct.
- Revenue share settings are correct where applicable.
- Communities are linked to the correct tenant.
- No service is enabled for a community unless the tenant has that service.

## Escalation

Escalate to technical support if:

- A tenant cannot be opened.
- A service does not appear on a member dashboard after being enabled.
- Payments are not recorded.
- A user has the wrong role.
- A community appears under the wrong tenant.
