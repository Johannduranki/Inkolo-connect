# SOP 03 - Tenant Admin Dashboard

## Purpose

This SOP explains how a tenant administrator manages their own tenant inside Duranki.

## Tenant Position In The Hierarchy

Duranki -> Tenant -> Community

A tenant belongs to Duranki. A community belongs to a tenant.

## Main Responsibilities

- Manage tenant profile.
- Configure tenant website and branding.
- View tenant communities.
- Create and edit communities.
- Enable services for communities.
- View members and activity under the tenant.
- Review transactions, reports, and revenue.

## Daily Start Procedure

1. Sign in using the tenant admin phone number and PIN/password.
2. Confirm the selected dashboard is the tenant dashboard.
3. Review tenant status, communities, services, users, and revenue.
4. Check whether any community or service requires action.

## Configure Tenant Details

1. Open Settings or Tenant Information.
2. Review company name, registration number, address, email, telephone, and website.
3. Update branding if required.
4. Save changes.

## Configure Website And Branding

1. Open Website & Branding.
2. Upload or confirm tenant logo.
3. Set primary colour.
4. Set secondary colour.
5. Set accent colour.
6. Add hero/banner image if available.
7. Enter domain name.
8. Enter website title, main heading, description, about text, contact details, and call-to-action.
9. Save.

The tenant website should automatically show the services enabled for the tenant.

## Create A New Community

1. Click Create New Community.
2. Enter community name.
3. Select community type.
4. Enter country, region, town, and location.
5. Upload or add community logo if available.
6. Enter community administrator details.
7. Add contact information and description.
8. Set status.
9. Select services available to the community.
10. Save.

The community is automatically linked to the current tenant.

## Manage Community Services

1. Open the community.
2. Go to Manage Services.
3. Tick services that should be available.
4. Untick services that should be removed.
5. Save changes.

Important: The tenant cannot give a community a service that Duranki has not enabled for the tenant.

## Community Membership Fees

If the tenant wants members to pay for dashboard access:

1. Enable Community Membership for the tenant.
2. Enable Community Membership for the required community.
3. Confirm the monthly fee.
4. Inform community administrators that unpaid members will have limited access.

## Review Activity

Review:

- New member registrations.
- Active services per community.
- Service applications.
- Paid subscriptions.
- Community membership status.
- Wallet/payment activity.
- Reports and revenue share.

## Control Checks

Every week, confirm:

- Communities belong to the correct tenant.
- Services match the tenant agreement.
- Community Membership fees are correct.
- Tenant branding and website information are current.
- Community admins have the correct access.
