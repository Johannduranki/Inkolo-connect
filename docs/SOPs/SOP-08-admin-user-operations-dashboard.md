# SOP 08 - Admin User Operations Dashboard

## Purpose

This SOP explains how an Admin User manages operational tasks without full Duranki Platform Admin ownership.

## Access

Route:

`/dashboard/admin-user`

## Main Responsibilities

- Manage member role assignments.
- Review member profiles.
- Review uploaded member documents.
- Create paid member reports.
- Review service subscription analytics.
- Manage community logos and colour schemes.
- Review legal agreement acceptance evidence.
- Support community and tenant operational staff.

## Daily Start Procedure

1. Sign in with the assigned Admin User phone number and PIN/password.
2. Confirm you are on the Admin User dashboard.
3. Check the role switcher if the user has multiple roles.
4. Review platform overview totals.
5. Review member and subscription activity.

## Manage Member Roles

1. Open the member role management section.
2. Search or select the member.
3. Review the roles currently assigned.
4. Add only the roles the member is authorised to use.
5. Remove roles that should no longer be available.
6. Save.

Important: The role switcher only shows roles assigned to the user.

## Review Member Profile

1. Select the member.
2. Open the member profile.
3. Confirm phone number, name, surname, and community.
4. Check uploaded documents if available.
5. Escalate incorrect identity or duplicate user records to Duranki Admin.

## Create Paid Member Report

1. Select Create Report.
2. Choose report type:
   - Members who paid per church/community.
   - All members paid for a month.
   - Members who paid per service.
3. Choose the month.
4. Choose church/community if required.
5. Choose service if required.
6. Select Create Report.
7. Review totals and rows.
8. Download CSV if needed.

## Manage Community Branding

1. Select the community.
2. Upload or confirm community logo.
3. Set primary colour.
4. Set secondary colour.
5. Set accent colour.
6. Set background colour.
7. Save.

## Review Legal Agreement Evidence

1. Select the member or service.
2. Review accepted agreement records.
3. Confirm service name, plan, document version, acceptance date, and retained evidence.
4. Export or download evidence where required.

## Control Checks

Before making any operational change:

- Confirm the user is the correct person.
- Confirm the correct community or tenant context.
- Confirm the requested role or report is authorised.
- Do not assign Platform Admin unless approved by Duranki leadership.
- Keep downloaded reports secure.
