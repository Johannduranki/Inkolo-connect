## Platform Hierarchy

Duranki is the highest level.

The operating structure is:

Duranki Platform -> Tenant -> Community -> Services -> Members

Examples:

- Duranki Platform -> Trader Connect -> Traders KZN -> Grant Distribution
- Duranki Platform -> Inkolo -> Inkolo KZN Community -> Funeral Services
- Duranki Platform -> ZUC -> ZUC Community -> Wallet, Payments, Marketplace

## General Rules

- Every user signs in with one phone number and PIN/password.
- If the user has access to more than one dashboard, they use the dashboard switcher.
- A platform admin can move between platform, tenant, community, and member views without logging out.
- A tenant admin manages only their own tenant.
- A community admin manages only their assigned community.
- Members see only the services enabled for their community.
- If Community Membership is enabled and unpaid, member access is limited until the membership fee is paid.
