SECURITY ACTION REQUIRED
The supplied screenshot contained live credentials. Ask Cycle to rotate the
notification secret, paywall secret and API caller password. Do not put the
replacement values into chat, source control, the frontend or this document.
No credentials from the screenshot have been installed or committed.

SERVER CONFIGURATION
Set these in the server secret manager or protected backend environment file:
  CYCLE_MODE=sandbox
  CYCLE_ENABLED=false
  CYCLE_LIVE_APPROVED=false
  CYCLE_MERCHANT_ACCOUNT=Duranki
  CYCLE_PAYWALL_SECRET=<sandbox paywall secret from Cycle>
  CYCLE_NOTIFICATION_SECRET=<sandbox notification secret from Cycle>
  CYCLE_PUBLIC_URL=https://<public Duranki domain>

The public URL must be an origin with HTTPS and no path/query/credentials.
Localhost is not a public callback endpoint. Provision HTTPS on the deployment
server first. Restart the backend after environment changes.
Hosted checkout does not use API caller credentials; those are needed for a
separately implemented direct API/reconciliation integration.

SANDBOX ACCEPTANCE
1. Obtain separate sandbox credentials from Cycle and configure the HTTPS URL.
2. Confirm with Cycle that notification id corresponds to the submitted chargeId
   and verify the current callback transaction shape against their sandbox.
3. Set CYCLE_ENABLED=true in sandbox only. Restart the backend.
4. Create a disposable payment request for a staging member and community.
5. As that member, open My payments and use Cycle's approved sandbox test cards.
6. Verify pending, approved, declined, cancelled, refund and partial-payment
   callbacks. Test invalid signatures, duplicate delivery and delayed callbacks.
7. Reconcile the register against Cycle's merchant portal; confirm exact amounts,
   references and callback retry handling. No real member payment is a test.

LIVE ACTIVATION
Only after sandbox acceptance, fulfillment integration and explicit release
approval: install rotated live keys, set CYCLE_MODE=live and
CYCLE_LIVE_APPROVED=true. Enable collection and restart. Validate a controlled
payment with the account owner and verify settlement independently. Do not
interpret configuration readiness as proof that Cycle has accepted a charge.
